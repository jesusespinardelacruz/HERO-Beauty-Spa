##  Sobre el proyecto

Este proyecto consiste en desarrollar la parte inicial de una página web para un centro de belleza y bienestar.

El ejercicio está enfocado en practicar la organización de componentes visuales, el posicionamiento de imágenes y la aplicación de estilos mediante Sass.

##  Características principales

-  **Navegación:** menú principal utilizando la etiqueta semántica `<nav>`.
-  **Hero:** sección de presentación con imágenes y contenido destacado.
-  **Fondos personalizados:** combinación de degradados, colores e imágenes superpuestas.
-  **SCSS modular:** separación y organización de estilos por componentes.
-  **Maquetación CSS:** uso de propiedades de posicionamiento, dimensiones y distribución.
-  **HTML semántico:** estructura organizada con elementos como `<header>`, `<main>` y `<section>`.


##  Instalación y ejecución

**1. Clonar el repositorio**

```bash
git clone https://github.com/USUARIO/REPOSITORIO.git
```

**2. Abrir el proyecto**

Abre la carpeta del proyecto utilizando Visual Studio Code.

**3. Compilar los estilos SCSS**

```bash
npx sass --watch scss/style.scss css/style.css
```

Adapta las rutas a la estructura real del proyecto.

**4. Visualizar la página**

Abre el archivo `index.html` en tu navegador o utiliza la extensión Live Server de VS Code.
